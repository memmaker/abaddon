# Abaddon

Felix' entry for the 7DRL Challenge 2024 (https://memmakerx.itch.io/abaddon, ranked #36 overall).
Built on the Heaven & Hell engine (Go, Ebitengine, tcell console mode).

## Source status

The jam-final source (commit 83d0756 plus the uncommitted jam work it was built with) was lost.
This repo reconstructs the game from the newest surviving Heaven & Hell source (2024-02-26, 25a869e)
plus the data files taken from the shipped 7DRL macOS build. Code changes after that point are
reconstructions, not the original jam code.

Build: `go build -tags embedded .`  Browser: `./build_web.sh`
